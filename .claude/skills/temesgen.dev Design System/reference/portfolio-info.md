# portfolio-info.md — pointer, not a copy

The canonical bio, experience, project, and CV facts live in
**`portfolio-info.md` at the repository root**. Read that file.

It is the file injected verbatim into the "ask my portfolio" chatbot's system
prompt — this one never was, despite what it used to claim.

This path used to hold a full duplicate. It drifted 59 lines behind the root
file and still advertised a superseded Google Drive CV link, so anything reading
it for "facts of truth" was being handed stale facts. Collapsed to a pointer per
the rule in `CLAUDE.md`:

> If maintaining two copies stops being worth it, collapse one into a one-line
> pointer at the other rather than letting them diverge.

If this skill is ever used outside this repository, copy the root file in at
that moment rather than reviving a permanent duplicate here.
