Portfolio 1 is the first version of Temesgen's personal portfolio site. Built with Next.js and Tailwind CSS, it shipped the core ideas this site iterates on: a project showcase, a skills overview, and a working contact pipeline (via Resend) — all wrapped in a responsive, dark-mode-first layout with SSR/SSG.

Kept online as a historical reference. The current site (temesgen.dev) replaced it with Astro 5 + a typed content collection model, server-rendered chat over a multi-provider LLM, and a tighter design system, but the structure and many of the project entries originated here.
